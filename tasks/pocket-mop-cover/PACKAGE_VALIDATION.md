Validated on 2026-11-23 using the existing native environment, without modifying
installed dependencies or the stock YAM robot.

- All **158 CPU tests pass** from a separate copy of the source with an empty,
  separate task output directory; see [package-cpu-tests.log](package-cpu-tests.log).
- All **140 Python modules parse**. All JSON files parse and local documentation

  and media tools resolve the same configured output root. Default output,
  scheduler helper and shared gate paths still select the original installation.

  using its archived assessor and archived path configuration. Output ownership

  core scene, dynamics, controller, reset, observation, scoring-logic, recorder
  and native GPU-verification files remain byte-identical to the pre-cleanup copy.

  media hashes were verified against the preserved external archive.

  native recordings or media binaries. Historical diagnostic scripts are retained
  because they remain shared dependencies; historical documents are labeled.

identity checks, and archives it alongside standalone post-recording assessors.

verification scope. [REPRODUCTION.md](REPRODUCTION.md) documents dependencies,
qualification regeneration and independent assessment.

GPU, demo, replay and model evidence comes from the completed R168–R171 runs.

hosted attempt requires matching fresh evidence; the submitted zero-result
attempt is already complete. The external scheduler and native runtime remain
